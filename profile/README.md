### ✨ Why RootEngine

<table>
<tr>
<td width="50%" valign="top">

#### ⚡ Live C++ hot reload
Save a file and see the change in the running editor. No restart, ever.

</td>
<td width="50%" valign="top">

#### 🎨 Stylized first
Toon shading, outlines and stylized post-processing, ready in one click.

</td>
</tr>
<tr>
<td width="50%" valign="top">

#### 🤖 Built for AI agents
A `root` CLI, readable text files and AI-ready docs. Claude Code, Codex and Gemini feel at home.

</td>
<td width="50%" valign="top">

#### 🧩 Visual where it matters
Dedicated editors for materials, sound, animation and game UI. Gameplay stays in code.

</td>
</tr>
<tr>
<td width="50%" valign="top">

#### 🌐 Multiplayer, natively
Host from your own PC or run a dedicated server, with the same code.

</td>
<td width="50%" valign="top">

#### 🍃 Light on your laptop
An editor designed to stay quiet: it only redraws when something changes.

</td>
</tr>
</table>
